## Important setup before publishing
1. Replace every `YOUR-GITHUB-USERNAME` with your actual GitHub username across all files.
2. Check contact email and service descriptions; keep only claims and technologies you can substantiate.
3. Verify all project descriptions, client confidentiality, and any claims about years of experience.
4. Add genuine approved project screenshots/testimonials when available. No confidential client data, credentials, or proprietary code.
5. Create a public repository named `YOUR-GITHUB-USERNAME.github.io` and upload all files to its root.
6. Repository Settings → Pages → Deploy from a branch → `main` → `/(root)`.
7. In Google Search Console, add/verify the site and submit `/sitemap.xml`.

## SEO expectations
This site uses unique page titles/descriptions, internal links, canonical placeholders, and relevant Person/Service structured data. These help search engines interpret the site but cannot guarantee indexing, ranking, rich results, or leads. Rankings depend on competition, content quality, site reputation, technical accessibility, and external signals.
